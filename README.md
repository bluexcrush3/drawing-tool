# Architectural Drawing Tool (間取り図作図ツール)

iPad・タブレット・PC対応の直感的な間取り図作図Webアプリケーションです。

## 主な機能
- **レイヤー構成**: 手書き下書き（フリーハンド）/ CAD清書（モジュール・グリッド吸着）
- **作図ツール**: 壁ツール、矩形、直線、部屋名・帖数タグ、寸法線
- **建具スタンプ**: 片開きドア、引違い戸、引違い窓、掃き出し窓、トイレ、洗面台、ユニットバスなど（90°回転・反転対応）
- **選択・移動モード**: 作図後の壁や建具、部屋タグの位置移動・回転・削除
- **クイック作図メニュー**: 右クリック / スタイラスペンボタンで瞬時に呼び出せるHUDメニュー
